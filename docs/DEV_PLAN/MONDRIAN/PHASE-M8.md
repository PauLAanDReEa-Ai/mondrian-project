# PHASE-M8: Corpus — one measured work per student, reviewed, rights-checked

> **Track:** L1 corpus. **Parallel lane** from M2 DONE to the end of term. Every student, every lane.
> **Status:** BLOCKED (M2 DONE)

## Goal

Grow the corpus from one reference work to one work per student plus the two remaining references, each a schema-valid `work.yml` with a `MEASUREMENT.md`, a named source, a recorded reproduction, EU and US rights rows, and a cross-lane peer review. This lane is where individual authorship lives inside the monorepo (D-01) and where the analyzer (M4) becomes a measuring aid whose output a student checks and signs. Measurement is time-boxed per work; precision is recorded, never inflated.

## Owners

- **Accountable:** instructor — rights gate, formative AI checkpoint and phase
  sign-off.
- **Responsible:** each student owns one measured work and its AI Review Log;
  the corpus lane lead owns conformance and aggregate statistics.
- **Review:** a human from another lane approves each work PR; the measuring
  student cannot self-approve.

## Deliverables

- `packages/works/works/<slug>/{work.yml, MEASUREMENT.md}` for ≥ 7 student works
  + references 2 and 3; `packages/works/CORPUS.md` index (slug, title, year,
  canvas, aspect class, provenance method/operator, accepted reviewer, rights,
  PR link).
- Issue per work from the `measurement.yml` template (fields: candidate work, catalogue, reproduction record, rights check owner).
- PR per work with the template filled (plan link, measurement source, reviewer from another lane); `CODEOWNERS` routes `packages/works/works/**` to the whole cohort so anyone can review and the measuring student cannot self-approve.
- CI step `conformance.sh` over the full corpus + the M3 fit test parametrised over all works + a "no images" check (`git ls-files | grep -Ei '\.(png|jpe?g|webp|tiff?)$'` limited to generated icons under `services/web/public/icons/`).
- `scripts/corpus-stats.py`: aspect-ratio spread, role-share distribution, swatch Δ table — the first numbers for `/method/` and for research.
- Mid-semester AI-critical checkpoint: each student points to one defended
  `REJECT` or one AI-proposed measurement/implementation choice they refused,
  naming the human verification. Coding-assistant evidence stays distinct from
  analyzer/ML metrics.
- `PHASE-M8-COLD-REVIEW.md`, `PHASE-M8-REPORT.md` (PARTIAL expected mid-term; DONE when the count matches the cohort).

## Scope

**In:** the above; the exclusions of pitch §5 enforced at issue triage
(lozenge, coloured-line, *Boogie Woogie*, multi-grey). **Out:** importing
external datasets. M2 already models `method: external`; M4 reports mappings
and licences, but a separate decision record must authorize any import.

## Prompt (Implementation Agent / Lane operator)

```text
Run PHASE-M8 per docs/DEV_PLAN/MONDRIAN/PHASE-M8.md. This phase is operated by the cohort; the agent's job is
tooling, triage checks and the report.

## Deliver
1. Issue template measurement.yml with required fields; a triage checklist comment that rejects excluded work
   types and missing rights rows.
2. CI: conformance over works/**, fit test over all works, image check, CORPUS.md regenerated by
   scripts/corpus-stats.py and diffed (fail if stale).
3. For each PR: verify MEASUREMENT.md names catalogue + reproduction (px size, crop) + wall time + uncertainty;
   verify the reviewer is from another lane (CODEOWNERS + branch protection enforce the count, the template
   enforces the lane).
4. Run the formative AI-critical checkpoint from
   AI-CRITICAL-OPERATING-ADDENDUM.md before M9. Record completion and PR/log
   location, not grades or student quotations, in the phase report.
5. Report: table of works with status; PARTIAL with the remaining list until the cohort count is reached.
6. Hand off for cold review at each PARTIAL checkpoint and at DONE — do NOT mark DONE yourself.

## Constraints
- A work without a named source is not merged; "looks right" is not a review.
- Analyzer output is accepted only when the student has checked at least three
  source primitives by hand—one point, one rectangle edge and one line
  thickness/extent—and says so in `MEASUREMENT.md`.
- No images committed except generated icons.
```

## Acceptance

- `scripts/conformance.sh packages/works/works` exit 0 over every work; count ≥ cohort size + 3 references.
- Every `work.yml` has non-empty `id`, `title`, `year`, `source`,
  method-specific provenance, `provenance.review.status=accepted`,
  `reviewed_by`, review date, `rights.eu` and `rights.us` (a `jq`/`yq` sweep in
  CI). Analyzer proposals cannot enter the corpus before this gate.
- Every merged PR under `packages/works/works/**` has ≥ 1 approval from a different lane than the author (checked with `gh pr list --state merged --json reviews,author` and the lane map).
- `git ls-files` shows no image files outside `services/web/public/icons/`.
- Aspect classes: at least one square-ish, one vertical, one horizontal across the corpus (from `corpus-stats.py`).
- Every student has completed the formative checkpoint or has a named,
  non-punitive follow-up before the defence.
- Cold review filed at DONE; blocking findings closed.

## Risks

- Students pick famous excluded works → triage checklist; the brief (M9) repeats the exclusions.
- Rights unresolved for a chosen work → the work stays in a `pending-rights/` folder excluded from the build until resolved; it still counts for the student's measurement grade (teaching) but not for publication.
- Measurement eats the term (pitch risk 43) → time-box per work in the issue; precision recorded.
